# Table Occupancy Detection (Computer Vision Prototype)

## Описание проекта

Прототип системы компьютерного зрения для анализа занятости столиков по видео.

Система обрабатывает видеопоток и автоматически определяет:

* свободен ли столик
* занят ли столик
* момент подхода нового посетителя

Дополнительно рассчитывается метрика:

> Среднее время ожидания между освобождением столика и приходом следующего гостя

---

## Цель

Реализовать упрощённый, но рабочий pipeline обработки видео:

* детекция людей
* отслеживание состояния столика
* сбор событий
* базовая аналитика

## Pipeline обработки

1. Загрузка видео
2. Ручной выбор ROI (области столика)
3. Детекция людей (YOLO)
4. Фильтрация:
   * confidence threshold
   * размер bounding box
5. Проверка нахождения человека в зоне столика:
   * iou (пересечение)
   * расстояние до центра
6. Стабилизация сигнала:
   * буфер кадров (anti-flicker)
   * временную устойчивость к пропаданию детекции (temporal reasoning)
7. Определение событий:
   * `EMPTY`
   * `OCCUPIED`
   * `approach`
8. Запись событий
9. Расчёт аналитики

---

## Логика определения состояния

Используется state machine:

* `EMPTY` → стол свободен
* `OCCUPIED` → стол занят

Переходы:

* `approach` — человек стабильно появился в зоне
* `empty` — человек стабильно ушёл

---

## 🔧 Ключевые улучшения (важно)

Для повышения качества были добавлены:

### 1. Фильтр temporal smoothing

Используется буфер кадров:

* событие фиксируется только после N подряд кадров

### 2. Временная устойчивость к пропаданию детекции (temporal reasoning)

Событие не фиксируется при кратковременных ошибках модели:

* стол не считается пустым при кратковременных потерях человека в рамке

### 3. Минимальная длительность occupancy

Игнорируются кратковременные подходы (шум):

* дети, проходящие люди, стоящие рядом

### 4. Комбинированный скоринг

Определение "человек за столом":

* IoU (пересечение с ROI)
* расстояние до центра стола

---

## Аналитика

Метрика:

> Среднее время ожидания столика

Важно:
Учитываются **только валидные случаи**, где человек действительно находился за столом достаточное время.

Это позволяет исключить:

* случайные проходы
* кратковременные появления

## Ограничения

* Нет различия между гостями и персоналом
* Не учитывается поза (сидит/стоит)
* Один столик (ручной ROI)
* Возможны ошибки при частичном перекрытии
